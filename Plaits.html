Case Study

PLAITS

A mobile meal planner app designed from scratch as a personal concept project.

Mobile UI UX Design Figma Meal Planning

Role

UI/UX Designer

Type

Personal Project

Tool

Figma

Platform

Mobile (iOS-style)

Overview

A meal planner that feels calm, not clinical

PLAITS is a personal concept project I designed entirely from scratch in Figma. The goal was to design a mobile meal planning app that feels warm and approachable rather than the sterile, data-heavy aesthetic most nutrition apps default to.

I wanted to prove I could take a fully formed product idea from nothing to a complete, polished set of screens without a brief, a client, or a template to lean on.

Scope

Full app coverage across 7 screen types

Rather than designing just a few hero screens, I mapped out and designed the complete app experience, including:

Splash Screen

Loading Screen

Home Planner

Discover Feed

Daily Tracker

Groceries

Profile

Process

Straight to high-fidelity

For PLAITS, I skipped wireframing and went directly into high-fidelity design in Figma. This was a deliberate choice for a personal concept project where the primary goal was to practice visual design, component building, and maintaining a consistent aesthetic across a full screen set.

I started by defining a color palette and type system, then built reusable components before designing any screens. That foundation meant every screen stayed consistent without having to manually match styles across the file.

Visual direction

I chose a warm, earthy palette of blush pinks, soft beiges, and muted browns. The goal was to make the app feel like something you actually want to open, not a fitness tracker that makes you feel guilty. Clean card layouts, generous whitespace, and food photography placeholders all contributed to that tone.

Key Design Challenge

Fitting multiple features without cluttering the UI

A meal planner has a lot of moving parts: weekly schedule, recipe discovery, nutrition tracking, grocery lists, and a user profile. Getting all of that into one app without making any single screen feel overwhelming was the core challenge.

How I addressed it

Each screen was scoped to one primary task. The Home screen shows the week at a glance without surfacing nutrition numbers. The Track screen handles macros and daily goals separately. The Groceries screen organizes items by category so the list never feels like a wall of text. A persistent bottom navigation bar keeps movement between sections fast and familiar without taking up too much space.

Outcome

A complete, portfolio-ready mobile UI

Designed a full 7-screen mobile app from scratch with no brief or reference template

Built a reusable component library in Figma that kept the visual style consistent across all screens

Demonstrated the ability to handle a multi-feature product while keeping each screen focused and clean

One of the strongest visual pieces in my portfolio in terms of color, layout, and overall polish
